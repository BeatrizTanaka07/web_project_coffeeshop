# Triple Espresso

## Descrição

Página web da cafeteria Triple Espresso.

### Funcionalidades

- Cabeçalho com horários e links de navegação;
- Seção de recomendações de vídeos de receitas;
- Formulário para reserva de mesas;
- Rodapé com contatos de redes sociais.

### Tecnologias utilizadas

- HTML: estrutura semântica.
- CSS: estilização.
- Metodologia BEM: padrão de nomenclatura das classes.
- Git: sistema de controle de versão.
- GitHub: plataforma de compartilhamento e publicação.

## Planos de melhoria

- Uma seção de avaliações dos clientes, onde eles podem avaliar com estrelas e comentários.
- Um menu para mostrar os produtos que são vendidos, ou pelo menos os best-sellers.
- Uma seção de novidades, como eventos, novos lançamentos ou produtos sazonais.
